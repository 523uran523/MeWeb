# Задача: личный сайт-портфолио Юрия Юрьева

Создать с нуля одностраничный статический сайт-портфолио (без сборки и без внешних JS-библиотек) на чистом HTML5 + CSS3 + vanilla JavaScript. Сайт должен продавать услуги разработчика: сайты, Telegram/MAX-боты, CRM и веб-приложения, простые приложения для Windows и Android, а также инженерное ПО (ЦОС, ПЛИС, Engee).

Язык интерфейса и контента — русский. Кодировка UTF-8. Все тексты ниже нужно использовать дословно или с минимальной литературной правкой, не теряя смысл.

## Файлы проекта

- `index.html` — вся разметка одностраничника и модального окна проекта.
- `assets/css/style.css` — все стили, адаптив, анимации.
- `assets/js/projects.js` — данные проектов в глобальной переменной `window.PROJECTS` (классический скрипт, без ES-модулей).
- `assets/js/main.js` — вся интерактивность (классический скрипт, без ES-модулей).
- `assets/img/projects/*.jpg` — уже существуют, только ссылаться на них.

Никаких внешних зависимостей, CDN-библиотек, фреймворков, сборщиков. Разрешены Google Fonts (Manrope + JetBrains Mono) через `<link>`, с системными fallback-шрифтами. Изображения — ленивые (`loading="lazy"`) везде, кроме первого экрана.

## Визуальный стиль

Тёмный неон + градиенты, премиальный и современный, но не «киберпанк-каша»:

- Фон: почти чёрный `#05060a`, поверхности `#0a0d14`, стеклянные панели.
- Акценты: циан `#22d3ee`, фиолет `#8b5cf6`, розовый `#f472b6`, лайм `#a3e635` (точечно).
- Крупная типографика, много воздуха, тонкие градиентные рамки, мягкие свечения.
- Атмосфера: аврора-пятна на фоне, едва заметная сетка, шум, световой след за курсором.
- Glassmorphism, градиентный текст на ключевых словах, кнопки с бликом при наведении.
- Плавные появления секций при скролле, stagger для карточек, счётчики, лёгкий 3D-tilt карточек (только на устройствах с hover и без reduced motion).
- Анимации не должны мешать чтению; всё завязано на `prefers-reduced-motion: reduce`.
- Полная адаптивность: 360, 390, 768, 1024, 1280, 1440+. Мобильное меню-оверлей.
- Доступность: контраст текста, видимый focus-visible, aria-атрибуты, закрытие модалки по Escape и клику по фону, блокировка скролла при открытой модалке.

## Сетка и поведение карусели

- Высота карточек фиксированная/по контенту, обложка 16:9.
- Шаг карусели = ширина карточки + gap. Пересчитывать при resize.
- Если карточек меньше, чем видно, стрелки/точки скрыть или задизейблить.
- Фильтрация перерисовывает трек и сбрасывает позицию на 0.
- Плавный `transform: translate3d(...)`, без layout thrashing.
- При открытой модалке страница не скроллится: `body.modal-open { overflow:hidden }`.
- Модалка должна корректно работать при прямом переходе по `#project/<id>`.
